# Moteur mpv

Tauri attend le moteur vidéo sous ce nom pour Windows x64 :

`mpv-x86_64-pc-windows-msvc.exe`

Le workflow GitHub fourni télécharge automatiquement une version Windows x64 récente de mpv et la renomme avant la compilation.

Pour compiler localement, placez vous-même `mpv.exe` dans ce dossier et renommez-le avec le nom ci-dessus.
